# Workflow: research

For prior art before a design decision, or a repo added to `references/`.

## Agents in order
1. **adf-researcher** — repo-analysis (Map / Dependencies / Ideas / Problems / License /
   Recommend); ideas, never copied code.
2. **adf-architect** — turn the recommendation into a structural decision.
3. **adf-documenter** — record the decision as an ADR linked from `decisions.md`.

## Exit gate
A written analysis with a license check and an adopt / adapt / avoid recommendation, and (when a
decision follows) an ADR in `decisions.md`.
